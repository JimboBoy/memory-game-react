# Emoji Memory Game 🎮

Ein lustiges Memory-Spiel mit Emojis, gebaut mit React + Vite.

## Spielen

Online: https://JimboBoy.github.io/memory-game-react

Oder lokal:
```bash
npm install
npm run dev
```

## Features

- 🎴 16 Karten mit lustigen Emojis
- ⏱️ Timer
- 🎯 Zug-Zähler
- 🏆 Highscore (localStorage)
- 📱 Responsive Design
- ✨ Animationen

## Tech Stack

- React 18
- Vite
- CSS Modules
